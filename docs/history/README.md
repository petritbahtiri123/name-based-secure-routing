# Historical NBSR documents

These files are retained as design history and evidence. They are not the
current implementation authority.

- [NBSR Protocol Vision v2](NBSR_Protocol_Vision_v2.pdf) remains useful for its
  security, lifecycle, ISP, federation, and anti-drift principles.
- Vision v2 is superseded wherever it treats a native client on every endpoint
  as the primary adoption path.
- [Vision v2 conformance matrix](../vision-v2-conformance.md) records the
  hardened prototype's July 2026 evidence against that earlier vision.

For current direction, read
[NBSR Protocol Vision V3.6](../architecture/NBSR_Protocol_Vision_V3.6.md).
The retained Vision V3 working document is also historical as of 2026-07-28.
