# Core v0.2 Deterministic Vector Package Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Produce a reproducible, language-neutral Core v0.2 vector package with raw CBOR/COSE/proof artifacts, exact expected errors, stateful scenarios, and a safe byte-for-byte regeneration check.

**Architecture:** Keep all reference generation and verification code under `scripts/core_v02_vectors`; runtime code under `nbsr/` must not import it. A strict JSON manifest indexes raw binary artifacts and expected outcomes. A vector-local reference verifier reuses the frozen RFC 8949 encoder and field validators but implements v0.2 body dispatch, COSE Sign1, proof, and scenario checks independently from future WP3 runtime.

**Tech Stack:** Python 3.12/3.13 target, `nbsr.protocol.cbor`, `cryptography` Ed25519, standard-library `dataclasses`, `hashlib`, `json`, `pathlib`, `tempfile`, Pytest, Ruff.

## Global Constraints

- Work only on `codex/nbsr-v3-wp0-wp1`; do not merge `main` and do not push without an explicit request.
- Do not add QUIC, DNS, origin-connection, Azure/cloud, runtime routing, or production registry behavior.
- Do not modify frozen Core v0.1 mappings, schemas, deterministic CBOR rules, state transitions, or COSE wrapper rules.
- Core v0.2 uses future version value `2` with exact ALPN `nbsr-quic-1`; no automatic v2-to-v1 fallback.
- Use the NBSR RFC 8949 deterministic encoder; never call `cbor2.dumps(..., canonical=True)`.
- COSE Sign1 uses tag 18, protected `alg=-8`, protected opaque byte-string `kid`, empty unprotected map, embedded payload, empty external AAD, and Ed25519.
- All generated keys are public test-only material. Runtime code and release packages must not import or package test seeds.
- Valid vectors contain no IP literal or Origin Endpoint. Invalid origin/IP inputs may use only RFC 5737 or RFC 3849 documentation literals.
- Every new behavior follows RED, GREEN, REFACTOR. Each task gets a separate commit.
- Stop after Task 9 for human review of the first generated byte package. Do not begin WP3 runtime or a second-language verifier.
