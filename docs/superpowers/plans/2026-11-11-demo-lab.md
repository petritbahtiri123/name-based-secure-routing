# NBSR Demo Lab Implementation Plan

> For agentic workers: use superpowers:subagent-driven-development for independent units and scoped review.

**Goal:** Local Windows/macOS source-based setup, browser scenario controls and offline CLI evidence verification.
**Architecture:** A separate tools/demo-lab application with fixed scenario adapters and owned bounded processes. Historical demo verifier and benchmark code remain unchanged.
**Tech stack:** Python 3.12–3.14, existing Go/Rust modules, static browser assets, thin PowerShell/shell wrappers.
**Spec:** https://chatgpt.com/space/page_a4f1d68fa5548191a85c7ca70684635c (Windows/macOS revision approved by Petrit).

## Global constraints
- Existing development branch; no commit/push; Petrit tests Windows before publication.
- No dependency/toolchain installation or live NBSR workloads in this implementation pass. Native Mac verification unavailable.
- Builds/trials maximum 120 seconds including cleanup, stop work by 95 seconds, two build jobs, 8 GiB initial free, stop below 6 GiB or after 2 GiB growth.
- Fixed scenarios only; historical/regression/live classifications separate; unknown or skipped evidence never PASS.
- No protocol/trust weakening, settings changes, credentials publication, remote benchmark access or edits to performance code.

## Review focus
- Origin/token replay and unauthenticated artifact reads.
- Process ownership and cancellation after leader exit.
- Receipt tampering or missing raw evidence.
- Interrupted preparation, missing sparse source and cache misses.
- Darwin path assumptions and native versus simulated verification.

## Task 1 Portable demo fixture support
- [ ] Add regression for Darwin build root without changing Windows/Linux semantics.
- [ ] Add portable standard-library Go transport fixture generator, exact SAN/EKU/key encoding validity semantics, exclusive owned output.
- [ ] Run only cached bounded focused checks; report unavailable native Mac tests.

## Task 2 Owned process supervisor
- [ ] Implement run_owned(argv, cwd, env, log_dir, timeout=95, cancel=None) returning exit_code, cleanup, reason, elapsed, output hashes.
- [ ] Windows suspended assignment/no breakaway; POSIX owned session and bounded group cleanup; fail closed on uncertain ownership.
- [ ] Regression tests for cancellation, timeout, output cap, abnormal leader exit, unknown platform; mocked Win32 separately labelled.

## Task 3 Evidence and scenario orchestration
- [ ] Strict versioned receipt with exact allowlisted raw evidence and independent verify(run_dir).
- [ ] Implement source inventory, preflight and offline build plan; side-effect-free check, explicit prepare/build paths.
- [ ] Allowed live adapter uses existing authority/client/destination. Negative scenarios use exact named regression binaries until native acceptance exists.
- [ ] UI may never infer authorization from HTTP 200 or missing output.

## Task 4 Local API and presentation
- [ ] Loopback app, short-lived one-use bootstrap, authenticated reads/writes, exact Host/Origin and fixed scenario IDs.
- [ ] Static dashboard with phases, expected/observed/cleanup and copied CLI verification command.
- [ ] Thin Windows/macOS launchers, dependency effects and repeatable setup docs; no automatic security bypass.

## Task 5 Review and handoff
- [ ] Scoped offline regression suite, syntax checks and one fresh correctness/security review.
- [ ] Copy only owned exact files from staging into development checkout with authorization, inspect diff/status.
- [ ] Update AGENTS area navigation and README; document validation limitations and user Windows trial steps.
