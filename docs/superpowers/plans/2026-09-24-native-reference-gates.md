# Native reference gates

Build read-only native reference gates before accepting any near-ceiling load.
Existing native finite packages are integrity evidence, not reference qualification.
Do not weaken existing Linux B5 or physical-core classifier contracts.

First provide a reusable post-close observer manifest validator: five or more
counterbalanced NBSR off/on pairs, independently verified peer packages, exact
source/workload/binaries/placement and within-pair authority equality. Reject
duplicate evidence, mixed observers, malformed metrics and undeclared modes.
Preserve every listed valid attempt. Report median paired goodput/p99 effects,
CV, all index hashes and any declared interruptions. Qualify only uninterrupted
cohorts with both absolute median effects and both throughput CVs at most 5%.
An interrupted cohort remains unqualified even if its aggregate numbers look good.
Checksums and declared order are not remote attestation or proof of undisclosed
attempt completeness. Direct does not enable the NBSR counter observer.

Then construct native finite depth-ladder references from existing pair gates,
existing finish_record and classify_ladder. Require exact source, fixed shape,
requested reports, repeat counts and complete matching observer qualification.
Keep rejected gates and all unfavorable valid rows. Scope references to their
measured native placement; never infer physical-core/server/WAN qualification.
Future paced loaders must bind the chosen reference to current source, shape,
binaries and both host identities before deriving 70–80% load.

Use literal RED tests, minimal implementation, focused verification and one
review. Validate rejection against already-retained unqualified native evidence;
do not rerun a noisy cohort simply to chase a passing gate. Full live resource
guards and long-duration native B5 remain separate implementation work.

Ruling: five finite repeats chosen in advance are accepted even when first-three
CV is low; the user requires a minimum of three, and retaining the additional
valid data strengthens rather than relaxes the classifier. All five remain in
the classification. Exact-source observer controls are required at every depth.

Verification: 12 observer RED + seven reference RED cases; 65 initial affected
tests PASS. Review found one minor exact-counter gap in observer qualification;
fractional-operation RED reproduced it, existing finish_record closes it, and
24 final observer/reference tests plus Ruff PASS. Scoped re-review clean.
Real retained ac40740c controls/reference are rejected by both CLIs with exit 2;
both finite ladders are UNRESOLVED. No rerun was performed to chase qualification.
