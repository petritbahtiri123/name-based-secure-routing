## Frozen WP1 work

[The WP1 Protocol Data Model plan](plans/2026-07-26-wp1-protocol-data-model.md)
remains the execution record for the frozen Core v0.1 scope. Tasks 1-4 are
represented by the current branch history. Tasks 5-8 require their normal
separate approval and must not absorb V3.6 OriginSet, Service Channel, native
origin-update, migration/resume, or handover work.

## Historical plans and specs

All other dated plans and specs in this directory describe the prototype or a
completed earlier decision cycle. They remain evidence and may explain current
code, but they do not override V3.6 or retroactively claim V3.6 conformance.
